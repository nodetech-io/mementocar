# Voice commands

Voice input works in English, Spanish and Catalan and uses the device's speech recognition and text-to-speech services.

## Creating a reminder

- Dictate the reminder directly, without a "remind me" prefix: "comprar pan al salir" / "buy bread when leaving". Explicit commands take priority over free text.
- The Quick Settings tile ("Nuevo aviso" / "New reminder") starts the same hands-free flow from any screen.
- Before saving, the app reads back the reminder, the car and the trigger, and accepts "save", "cancel", "repeat", "change text", "on entry" or "on exit". A correction requires a new confirmation.
- After saving, it announces the result.
- The flow cancels after three failed replies or eight recognition rounds. The on-screen buttons remain available when speech services are not.

## Pending alerts

The same entry points handle commands for the selected car's pending alerts:

- "marcar llaves" / "mark keys" marks one item as done, matched by name. If several items match, the app asks which one.
- "posponer" / "snooze" snoozes the latest alert.
- "todo listo" / "all done" completes every item of the latest alert after a spoken and on-screen yes/no confirmation.

With no pending alert, the app says so.
